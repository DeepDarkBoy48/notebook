# 七维深度解构框架

| 维度 ID | 维度名称 (CN/EN) | 定义与功能 | AI 生成逻辑映射 |
| :--- | :--- | :--- | :--- |
| **D1** | 布局容器 (Layout Containers) | 信息的物理空间结构，视线的流动路径。 | **骨架 (Skeleton)**：施加第一道空间约束，防止概念溢出。 |
| **D2** | 主题内容 (Theme Content) | 数据的语义逻辑与叙事方式。 | **灵魂 (Soul)**：决定图表的叙事引擎，如对比、演化、层级。 |
| **D3** | 美术风格 (Art Style) | 整体的视觉语调与艺术流派。 | **皮肤 (Skin)**：定义情感色彩与受众定位，如信任感、紧迫感。 |
| **D4** | 视觉媒介 (Visual Medium) | 模拟的物理材质与呈现手段。 | **物质 (Matter)**：定义光影逻辑、质感、物理渲染属性。 |
| **D5** | 排版细节 (Layout Details) | 微观层面的构图与视线引导。 | **微调 (Tuning)**：涉及对齐、留白、视觉层级，降低认知负荷。 |
| **D6** | 文本内容 (Text Content) | 具体的文字信息、标签系统与字体。 | **界面 (Interface)**：利用 OCR 级能力精准传达核心数据。 |
| **D7** | 技术参数 (Tech Parameters) | 宽高比、分辨率、相机视角。 | **工程规范 (Specs)**：控制生成的物理属性，如 4K、景深控制。 |
