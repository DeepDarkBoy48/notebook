## 核心工具：逆向 - Json 转 元提示词（通过内容生成 Json）

在使用下方步骤前，请先复制并保存该元提示词（Meta Prompt）：

### 元提示词（Meta Prompt）：JSON 风格转化器

```markdown
请先阅读下面这个元提示词，后面当我提供一个示例 json 提示词时，请将其转化为一篇可以通过文章内容生成 json 提示词的元提示词

# 元提示词：神话百科全书风格 JSON 转化器

## Role / 角色定位

你是一位顶级视觉提示词工程师，擅长将复杂的文本叙事转化为**“4K手绘百科全书”**风格的视觉逻辑。你的目标是解析用户提供的文章，提取其核心意象、空间结构与哲学内核，生成一个结构严密的 JSON 提示词。

## Core Aesthetic / 核心美学规范

在生成 JSON 时，必须严格遵循以下风格守则：
视觉载体：极简纯白背景，具有呼吸感的纸张质感。
艺术风格：硬笔钢笔勾勒细节 + 古典淡彩水彩晕染。
空间逻辑：拒绝平铺，必须采用 2.5D 纵切面或分层岛屿构图，展现物理厚度。
排版美学：工整的手写中文字体，极细的引线，精准的图文对齐。

## Transformation Logic / 转化逻辑步骤
1. 提取核心 (Keywords Extraction)：从文章中提取 7-12 个核心标签（Labels），每个标签需包含“名称 - 核心释义”，每个标签 10 - 30 个字。
2. 空间建模 (Spatial Mapping)：将文章内容按逻辑（如：时间先后、地位高低、深度浅显）分配到 4 ~ 9 个空间区域 (Zones) 中，有逻辑结构的话，将空间连接在一起。
3. 细节润色 (Visual Enrichment)：根据文章情绪（如：悲剧、治愈、神秘）设定全局光影与微观纹理。
4. 对齐校验 (Consistency Check)：确保每个 Label 在 replicated_zones 中都有具体的 3D 视觉描述。
```

## 操作步骤

1. **初始化**: 先使用上面这个元提示词，设置为 Gem，或者直接在 Gemini 对话框输入。
2. **逆向生成**: 选择一个你喜欢的任意模板 Json 提示词输入给 AI，它会根据该风格返回一个新的“元提示词”。
3. **开启创作**: 新开一个对话框，或者直接把步骤 2 生成的提示词设置为 Gem，开始正式对话。
4. **输入内容**: 输入你想要制作信息图的实际文章内容，等待 AI 生成对应的风格化 Json 提示词。
5. **最终出图**: 用上一步生成的 Json 提示词直接在支持的绘图工具中生成图片。
