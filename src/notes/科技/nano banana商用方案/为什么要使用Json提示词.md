# 为什么要使用Json提示词 | SSR

Json提示词最重要的作用是将提示词结构化，虽然我们不会直接手写Json提示词，但可以直接让AI帮我写好，再进行调整，形成一个模板或者参考。

这些Json提示词能够让所有的提示词结构变得统一。

最直接的好处是，比如我看到有一个提示词绘制的图片我非常的喜欢，想要用这种风格来绘制某个内容的信息图。

我们可以直接通过AI，用这个内容清洗掉之前提示词的信息内容，保留结构和风格，生成一个新的Json提示词。

如果你写一个很简单的提示词，香蕉Pro解读的时候会自动脑补，随机发散，你如果用同一个提示词的绘制几次，你会发现结果各不相同但又有相似之处。

具体到信息图，你可以通过Json提示词很方便的指定 风格、布局、背景、视觉元素、文字内容，甚至边框，字体等等地方。

你可以直接给AI一个Json模板，让AI根据你给的信息内容来填充模板输出一个全新的提示词。

用这个提示词生成图片，如果不满意，再针对性的让AI调整Json提示词，

比如风格不喜欢就调整风格，标题不喜欢就调整标题，让信息图的一切变得可控。

使用Json提示词的好处有很多：

- 你可以针对某个出图需求设计一个Json模板，方便你保持整体风格；
- 通过详细的指定所有细节来避免让AI自由发挥；
- 你可以很方便的拆解并模仿任何图片；
- 你可以将复杂的提示词结构变得清晰；

如果你有特别的需求，也可以通过增加Key、减少Key，自己定义一个属于自己的信息图Json模板，比如你需要定制边框样式，或者增加一个常用水印。

除了信息图，其它类型的图片当然也可以用Json结构的提示词。

Json提示词只是为了方便我们自己，模型并不在乎，你可以通过AI将提示词转换成任意形式，这不会影响模型理解提示词本身。

我们在使用Json提示词时也不用拘泥于把所有的内容都写在Json之中，你如果临时有什么想法，直接写在Json之外也没关系。
