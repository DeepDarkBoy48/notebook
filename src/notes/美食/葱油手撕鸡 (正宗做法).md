# 葱油手撕鸡 (正宗做法)

这也是一道非常经典的广式凉菜，重点在于**葱油的香气**和**鸡肉的嫩滑**。做法简单，但细节决定成败。

## 🛒 食材准备

### 主料

* **鸡腿**：2-3个 (或者三黄鸡半只，鸡腿肉质最嫩最不容易失败)

### 煮鸡料 (去腥)

* **生姜**：3-4片
* **小葱**：2根 (打成结)
* **料酒**：1大勺
* **清水**：足量 (需没过鸡肉)

### 葱油酱汁 (灵魂)

* **小葱**：5-8根 (不用吝啬，要多)
* **蒜末**：3-4瓣
* **姜末**：少许
* **洋葱**：1/4个 (可选，增加复合香气)
* **食用油**：约60ml
* **调味**：生抽2勺、蚝油1勺、白糖1小勺、盐少许、白芝麻少许

---

## 👨‍🍳 详细步骤

### 第一步：煮鸡 (“煮”不如“焖”)

1. **冷水下锅**：鸡腿洗净，冷水入锅，水量要能完全淹没鸡肉。这步加入**姜片**、**葱结**和**料酒**。
2. **大火去沫**：开大火煮沸，撇去表面的浮沫。
3. **小火慢煮**：转中小火煮 **8-10分钟**。
4. **关火焖熟**：关火，盖上盖子，利用水的余温继续**焖10-15分钟**。
   * *判断标准*：用筷子能轻松扎透鸡腿最厚处，且拔出无血水冒出，即为全熟。
5. **冰水冷激**：(关键步骤) 捞出鸡腿，立即放入**冰水**中彻底冷却。这一步能让鸡皮瞬间收缩变得Q弹，肉质更紧致滑嫩。

### 第二步：熬制葱油

1. **备料**：小葱切长段（葱白和葱叶分开），洋葱切丝。
2. **熬葱油**：锅中倒入食用油 (比平时炒菜多一些)，冷油下入**葱白**、**洋葱丝**和**姜片**。
3. **慢炸**：全程**小火**慢炸，直到葱料炸至焦黄酥脆（不要炸糊发苦），捞出残渣丢弃。
4. **出香**：此时锅中留下的就是金黄浓郁的葱油。

### 第三步：调制酱汁

1. 准备一个小碗，放入**蒜末**、**姜末**、**细葱花** (葱叶部分) 和 **白芝麻**。
2. 将滚烫的**热葱油**淋入碗中，“滋啦”一声激发出调料的香味。
3. 趁热加入 **2勺生抽**、**1勺蚝油**、**1小勺白糖**、**少许盐**，搅拌均匀成酱汁。

### 第四步：手撕拌匀

1. **撕鸡**：将冰镇好的鸡腿沥干水分，戴上手套，顺着纹路撕成条状（去骨）。*手撕的断面参差不齐，比刀切更容易吸附酱汁。*
2. **拌匀**：将撕好的鸡肉放入大碗，倒入只需做好的葱油酱汁。
3. **抓拌**：充分抓拌均匀，如果喜欢香菜或花生米，也可以在这一步加入。
4. **静置**：装盘后静置5-10分钟再吃，让味道渗入肉里，风味更佳。

---

## 💡 成功秘诀

1. **焖熟**比一直开火煮熟的鸡肉要嫩得多。
2. **冰水**是鸡皮脆爽的关键，没有冰块就用冷藏过的凉白开。
3. **葱油**要小火慢熬，火大容易苦，葱油是这道菜的灵魂，可以一次多做点拌面用。
